# Introducción — Initial Access

El acceso inicial en un ejercicio de Red Team puede encontrarse en:
- Una vulnerabilidad web
- Vulnerabilidad en la cadena de suministro
- Phishing (Ingeniería Social)

## Taxonomía de un Phishing

| Componente | Descripción |
|-----------|-------------|
| **Delivery** | Técnica para entregar el paquete a la víctima |
| **Container** | Formato contenedor para empaquetar los archivos |
| **Trigger** | Medio para activar la ejecución del payload |
| **Payload** | Código malicioso a ejecutar |
| **Decoy** | Archivo legítimo que se muestra a la víctima |
