# 135 — RPC / MSRPC

---

## Enumeración

```bash
rpcclient -U "" -N <IP>                        # null session
rpcclient -U'%' <IP>                           # sin contraseña
rpcclient -N <IP> -U 'usuario%contraseña'      # autenticado

impacket-rpcdump -p 135 <IP>                   # listar servicios RPC
```

---

## Comandos RPCClient

```bash
# Dentro de rpcclient:
enumdomusers                                    # listar usuarios del dominio
enumdomgroups                                   # listar grupos
queryuser <usuario>                             # info de un usuario
queryusergroups 0x46c                           # grupos de un usuario por RID
querygroupmem 0x200                             # miembros de un grupo

# Cambiar contraseña (si tienes permisos)
setuserinfo2 <usuario> 23 'NuevaContraseña!'
setuserinfo christopher.lewis 23 'Password123'
```

---

## Qué buscar

- Null session activa → enumerar usuarios/grupos sin creds
- `queryuser` + descripción → contraseñas en campos de descripción
- Permisos para cambiar contraseñas de otros usuarios
